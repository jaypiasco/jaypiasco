## 🚀 Featured Projects

### 🎬 [FableMotion — Autonomous AI Video Generation Platform](https://fablemotion.me)
*Aug 2026 – Sep 2026* • [Live Demo](https://fablemotion.me)
> An end-to-end, fault-tolerant pipeline converting a single prompt into fully assembled, cross-platform distributed vertical drama videos.

- **Multimodal Synthesis Pipeline:** Orchestrated Gemini 3.5 Flash-Lite, Imagen 3, and Veo 3.1 into a decoupled 5-phase production engine; locked in character identity across shots using visual reference conditioning.
- **Fault Tolerance & State Machine:** Built an idempotent state engine with atomic disk persistence and exponential backoff, preventing redundant API spend and resuming seamlessly from mid-pipeline crashes.
- **Observability & CI/CD:** Instrumented Prometheus, Grafana, and Langfuse for p95 latency percentiles and real-time USD cost tracking; built automated regression gates in GitHub Actions to validate prompt and character continuity before deployment.
- **Media Processing & Distribution:** Containerized asynchronous FastAPI backend on Google Cloud Run with headless FFmpeg concatenation, faster-whisper word-level subtitle burns, and multi-platform OAuth publishing (YouTube Shorts, Instagram, TikTok).

*Stack: Gemini, Imagen, Veo, faster-whisper, FFmpeg, FastAPI, Pydantic, JSON Schema, Docker, Cloud Run, Supabase, GCS, GitHub Actions, Langfuse, Prometheus, Grafana*

### ♻️ [EcoPoints — IoT-Integrated Smart Recycling Platform](https://ecopoints.org)
*Nov 2025 – Jun 2026* • [Website](https://ecopoints.org)
> Edge AI recycling kiosk powered by computer vision and hardware actuator controls.

- **Edge Computer Vision:** Trained YOLOv11 instance segmentation models for real-time edge material classification on a Raspberry Pi.
- **IoT & Hardware Control:** Programmed Python control logic for multi-sensor arrays and motorized sorting actuators connected via WebSockets to a Flask API.
- **Cloud Architecture:** Implemented OAuth2 QR-code session pairing between physical kiosks and Next.js user web portals backed by PostgreSQL and Redis.

*Stack: Next.js, Python (Flask), PostgreSQL, Docker, Redis, YOLOv11, WebSockets, Raspberry Pi, Expo*
